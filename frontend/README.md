# Notes UI

React + TypeScript + Vite + Tailwind SPA for the Notes API.

Setup, dev workflow, and E2E tests are documented in the [project root README](../README.md#web-ui-react).

```powershell
npm install
npm run dev      # http://127.0.0.1:5173 — proxies /notes to API on :8000
npm run test:e2e # Playwright smoke test (starts dev server)
```
